# RL_for_Option_Pricing
In this repository I consolidate the results for the Reinforcement Learning course at OpenCampus in the summer semester 2023. 

I include the presentation and the necessary codes for replication. The goal was to study the usabilility and efficiency of RL-Algorithms for Option Pricing. Especially in the case of American Call- and Put-Options - I like to hightlight the game-theoretic character of these financial products. In order to price such derivatives - we need to know or at least be able to estimate the intrinsic underlying value properly. 

Due to the fact that financial markets are moving and static conditions are never satisfied - closed-form solutions might only be possible for simplistic use cases.
The RL-Approach opens a new machine learning driven solution for such problems. It's strength lies in the possibility to generalize to more complex Pay-Off-Proflie and model-free market conditions.
